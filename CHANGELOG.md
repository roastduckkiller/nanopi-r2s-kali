# Changelog

## v0.1.0 — 2026-09-23

Initial experimental source release:

- Native ARM64 Kali rootfs build for the tested NanoPi R2S vendor layout.
- GPT validation and compact 2.5 GiB image assembly without flashing a device.
- Explicit SSH public-key provisioning, first-boot host keys and no shared password.
- Headless networking, persistent OverlayFS integration and zram configuration.
- Optional user-local Node 24.21.0 / Pi 0.87.1 installer.
- Remote model configuration examples without private endpoints or credentials.
- English/Chinese setup instructions, hardware validation notes and CI checks.

No prebuilt SD image or vendor binaries are distributed in this release.
